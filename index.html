Simplifying Chord Recognition: A Case Study with NEK

This case study explores NEK, an open-source VST3 plugin for MIDI and audio chord recognition, designed to simplify chord detection in educational applications. By analyzing both MIDI and audio inputs, NEK offers an accessible framework for developers aiming to build chord recognition tools. Download the paper below to learn more about the chord recognition algorithms NEK uses and how you can incorporate them. You can also access the NEK plugin to delve into the code or experiment with its features.

Chord Recognition Approach

To reiterate, NEK is a music education software plugin that functions as a MIDI or audio chord recognition tool. For audio, NEK utilizes an algorithm by Adam Stark, which breaks down an audio signal into frames and assigns a label based on the residual energy in the chromagram. Essentially, with the aid of a bit mask, the chord label that minimizes the calculated residual energy is assigned as the designated chord.

For MIDI events, NEK projects the state of MIDI messages to a buffer and uses an intuitive approach to name the intended chord. Additionally, the algorithm is robust to inversions, meaning your database only needs to contain the default interval relationships for the chord, without worrying about all its corresponding inversions.
